A single original one-line roast of a smart fridge, written by `main.ts` to `/output/entry.txt` for the make.fun bounty "One Line, One Laugh: Roast Your Fridge" — the roast targets the fridge's touchscreen (recipes never cooked, calendar never checked, camera filming midnight ice cream) and lands its twist in the last few words.

## Run it

```sh
node main.ts
```
